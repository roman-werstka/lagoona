# Lagoona

Hotel network landing page built as a frontend practice project.

The project is focused on semantic HTML structure, clean CSS styling, reusable layout patterns and responsive web design.

## Demo

GitHub Pages: coming soon

## About

Lagoona is a multi-section hotel website created as an educational frontend project.

The page includes:

- Header navigation
- Special offers section
- About section
- Services section
- Advantages section
- Accommodation section
- Contacts
- Call-to-action buttons

## Technologies

- HTML5
- CSS3
- Flexbox
- BEM-style class naming
- Responsive Web Design
- Normalize.css

## Features

- Semantic HTML structure
- Multi-section layout
- Reusable CSS classes
- Flexbox-based layouts
- Styled navigation and buttons
- Image-based content cards
- Hotel service and accommodation sections


Then open `index.html` in your browser.
